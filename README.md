# Data Analytics Portfolio

A collection of end-to-end data analysis projects showcasing skills in Excel, Python, SQL, Power BI, and Generative AI — built to demonstrate both Data Analyst and Business Analyst capabilities.

## Projects

### 📊 [HR Employee Attrition Analysis](./hr-attrition-analysis)
Analysis of employee attrition patterns across departments and roles using the IBM HR Employee Attrition dataset. Includes a Power BI dashboard and a Generative AI-powered natural language Q&A feature over the dataset.
Tools: Excel, Python, SQL, Power BI, Generative AI (Gemini)
Key finding: Overall attrition rate of 16.12%, with Sales Representatives showing the highest attrition at 39.8%.
